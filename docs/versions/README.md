# KeySwiper APK version archive

Every successful APK build from the `main` branch is preserved permanently as a GitHub Release and receives its own version page.

Each entry records the exact app version, Android version code, CI run, Git commit, SHA-256 checksum, permanent APK download and the complete changelog section for that version.
